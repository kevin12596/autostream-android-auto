# AutoStream

**朋友第一次安裝：請先閱讀 [完整安裝與操作教學](docs/INSTALL.zh-TW.md)。** 目前原始碼版本為 v0.4.14 / build 18。




Android Auto 車機上的實驗性 YouTube WebView App，支援手機搜尋選片、寬螢幕雙欄、續播與影音延遲設定。請在停妥車輛時觀看及操作。

- [下載正式 APK](https://github.com/kevin12596/autostream-android-auto/releases/latest)
- [第一次安裝：完整步驟說明](docs/INSTALL.zh-TW.md)
- [建置、簽章與發布](docs/MAINTAINERS.md)
- Apache-2.0 授權，見 [LICENSE](LICENSE)。非 Google、YouTube 或 BMW 官方產品。

在 Android Auto 車機畫面上顯示 WebView（YouTube）的實驗性 App。

原理：以 **NavigationTemplate** 取得車機地圖 Surface → 建立 **VirtualDisplay**（`OWN_CONTENT_ONLY | PRESENTATION`）→ 用 **Presentation** 在其上顯示硬體加速的 WebView。車機畫面的尺寸／DPI 完全取自車機 SurfaceContainer，與手機本身螢幕（摺疊／展開、旋轉）無關。

v0.4 起預設走 GL 管線：VirtualDisplay → SurfaceTexture（OES，獨立 render thread / EGL14）→ 時間戳環形緩衝（FBO）→ 車機 Surface（EGL window surface），用來做「影音同步（影片延遲）」。GL 初始化失敗時自動退回 VirtualDisplay 直接輸出到車機 Surface（延遲功能停用，其餘照常）。

## 播放功能

- **背景續播**：切到其他車機 App（例如 Google Maps）時聲音不中斷、WebView 不銷毀；只把輸出從車機 Surface 拔掉，回來時直接接回。只有 Android Auto 工作階段結束（斷線／關閉 App）才完整釋放。
- **網頁原生操作**：使用 YouTube 網頁的播放、暫停、進度、下一部與全螢幕按鈕。原生全螢幕由 WebChromeClient 顯示，返回鍵可離開全螢幕。
- **畫質鎖定**：每次載入/切換影片時呼叫 YouTube 播放器 `setPlaybackQualityRange` 鎖到可用的最高畫質；手機端可設上限：最高（預設）/ 1080p / 720p / 自動。
- **續看位置**：播放中每 5 秒、暫停時、切到其他 App 時、工作階段結束時記錄影片 ID + 秒數；下次冷啟動直接開 `watch?v=…&t=…s`（手機版網址）。影片播完會清除。
- **影音同步（AV 延遲）**：見下節。

> ⚠️ 僅供個人研究／側載使用。這不是 Google 允許上架的用途（導航類別 App 顯示影片違反 Android Auto 政策）。

## 安裝

1. 從對應 GitHub Actions **Build** 下載版本化 APK artifact，解壓取得 `AutoStream-v0.4.14-build18.apk`。
2. 手機允許「安裝未知應用程式」（設定 → 應用程式 → 特殊存取權 → 安裝未知應用程式 → 對檔案管理員/瀏覽器允許）。
3. 使用 InstallWithOptions 安裝 APK，將安裝來源指定為 `com.android.vending`（Google Play）。直接透過瀏覽器或檔案管理員安裝，可能導致 Android Auto 不顯示 App。
4. 開啟 Android Auto 開發者模式：
   - 手機 設定 → 已連結的裝置 →（連線偏好設定）→ Android Auto（或直接開 Android Auto App 設定）。
   - 捲到底部連點「版本」約 10 次 → 確認開啟開發人員設定。
   - 右上角選單 → **開發人員設定** → 勾選 **「不明來源」（Unknown sources）**。
5. Android Auto 設定 → **自訂啟動器** 確認 AutoStream 有被勾選顯示。
6. 連上車機（有線或無線），在車機啟動器中點選 AutoStream。

> 本 APK 為 debug 版，HostValidator 允許所有 host（`ALLOW_ALL_HOSTS_VALIDATOR`）；release 版僅允許 car-app library 內建的 `hosts_allowlist_sample`。

## 登入（一次性）

1. 在手機開啟 AutoStream → 按 **「登入 Google / YouTube（一次性）」**。
2. 會在 App 內 WebView 開啟 `https://accounts.google.com/ServiceLogin?continue=https://m.youtube.com`，使用不含 `wv` / `Version/4.0` 的 Chrome UA。
3. 登入完成、看到 m.youtube.com 後按返回即可。Cookie 會持久化（`CookieManager.flush()`），車機端 WebView 共用同一個 profile / CookieManager。
4. 要登出：按「登出（清除 Cookie）」。

## 通知與電池

- 按 **「允許通知」**（Android 13+ 前景服務通知需要）。
- 按 **「電池最佳化設定」** → 找到 AutoStream → 設為「不最佳化」。

### ColorOS（OPPO Find N6）額外設定

ColorOS 會很積極地殺背景程式，建議全部做：

1. 設定 → 電池 → 更多設定（或「應用程式耗電管理」）→ AutoStream → 開啟 **允許背景活動**、**允許自動啟動**、**允許關聯啟動**（各版本名稱略有不同）。
2. 設定 → 電池 → **關閉 AutoStream 的電池最佳化**（「不最佳化」）。
3. 開啟最近任務（多工畫面）→ 對 AutoStream 卡片下拉或點右上角選單 → **鎖定**（出現鎖頭圖示），避免一鍵清除時被關掉。
4. 若 Android Auto 本身也被殺，對 **Android Auto** App 做同樣的設定。

摺疊／展開手機不會影響車機畫面：車機 Surface 與手機設定無關，CarAppService/Presentation 不會因手機 configuration change 被重建。

## 手機搜尋

1. 開啟手機 AutoStream，在版本號下按「搜尋 YouTube（鍵盤／語音）」。
2. 輸入關鍵字，或按「語音輸入」使用手機系統辨識；語音辨識完成後可先修改文字。
3. 按「在手機搜尋」或鍵盤搜尋鍵，在 App 內查看手機版結果。
4. 要改在車機查詢，先連線並在車機開啟 AutoStream，再按「傳送搜尋到車機」。請回車機 AutoStream 查看結果。兩個搜尋動作分開，傳送到車機不會同時在手機開啟另一個結果頁。

## 車機操作

- 按車機上方「搜尋」→ 用鍵盤輸入，或點搜尋列的麥克風說出關鍵字 → 停止輸入 1.5 秒會自動送出；也可按搜尋頁上的「搜尋」立即送出，顯示手機版結果。鍵盤只在停車時顯示；車機語音辨識由 Android Auto 提供。請使用此搜尋入口，WebView 裡的輸入框無法可靠叫出車機鍵盤。
- 搜尋頁按返回取消並回到原頁；再次開啟搜尋會帶入本次連線中上次送出的關鍵字。其餘首頁導覽與播放控制直接操作 YouTube 手機版網頁。
- 播放操作直接使用 YouTube 原生網頁按鈕。影片左側中段雙擊回溯 10 秒、右側中段雙擊快進 10 秒；點中央或原生播放按鈕照常操作。返回鍵順序：離開網頁全螢幕 → 網頁上一頁 → 離開 App。
- 點擊畫面：轉成 `ACTION_DOWN/ACTION_UP` 注入 WebView。
- 按地圖區的「平移」(PAN) 按鈕進入平移模式後，可拖曳捲動（合成拖曳事件）與甩動（fling）。
- 縮放手勢：基本 `zoomBy`（stub 等級）。
- 音訊焦點只由 WebView 管理。手機端「儀表板媒體整合」是另一個實驗性選項，預設關閉；發生瞬間暫停時先保持關閉。

## 影音同步（AV 延遲）

無線 Android Auto 常見「聲音比畫面慢」（嘴型先動、聲音後到）。App 可以把**畫面延後**顯示來對齊聲音：

- 調整方式：
  - 手機 App →「影音同步（影片延遲）」滑桿，0–800 ms，每格 50 ms。
  - 設定即時生效並保存。預設 0（不延遲＝直通）。
- 怎麼調：播一段有人講話的影片，**嘴型比聲音先動 → 加大延遲**；調到嘴型與聲音對上為止。調過頭（聲音比嘴型先）就減少。
- ⚠️ 只能修正「聲音慢於畫面」。若是**畫面慢於聲音**，此功能無法修正（不能讓畫面提前）。
- 延遲 > 0 時畫面約以 30 fps 擷取（高解析度時會自動降低擷取幀率以控制記憶體，每幀 寬×高×4 bytes，上限約 192 MB）。
- 延遲期間網頁操作的畫面回饋也會晚同樣的時間（聲音與操作本身不延遲）。

## 解析度提示

車機上看到的清晰度受兩層限制：

1. **YouTube 串流畫質**：App 會自動鎖最高（或手機設定的上限）。
2. **Android Auto 投影解析度**：Android Auto → 開發人員設定 → **影片解析度**（Video resolution），可試 **1080p**（預設多半是 720p/自動）。是否有效取決於車機（BMW iX 的主機是否支援該解析度）；不支援時會被車機忽略或連不上，改回「自動」即可。

## 建置

本機不需要 Android SDK，全部由 GitHub Actions 建置（`.github/workflows/build.yml`，push 或手動 `workflow_dispatch` 觸發），輸出以 APK 檔名命名的版本化 artifact。

本機若有 JDK 17 + Android SDK：`./gradlew assembleDebug`。

## 與導航並排

Android Auto 的並排版面由 host 管理，目前本 App 不能把任意 YouTube 網頁影片放進導航旁的媒體卡片。YouTube Music 類型的媒體卡片顯示的是音訊資訊與控制；若改做 MediaBrowserService／MediaSession 音訊整合，可以研究「導航＋封面／播放控制」，但不會得到「導航＋影片」。本版沒有加入分割影片或改變 App 類別。

參考：[官方媒體 App 說明](https://developer.android.com/training/cars/media)、[Android Auto 內容區域與 Dashboard](https://developers.google.com/cars/design/android-auto/product-experience/system-ui/content-area)。

## 已知限制

- **Google 仍可能封鎖 WebView 登入**（「此瀏覽器或應用程式可能不安全」）。目前以移除 `wv` 標記的 Chrome UA 嘗試，但不保證成功；Google 隨時可能改變偵測方式。
- **服務條款風險**：在 WebView 中播放 YouTube、以導航類別在車機顯示影片，可能違反 YouTube / Google / Android Auto 條款，帳號或功能可能受影響，風險自負。
- 切到其他車機 App 時聲音持續播放；但若車機 Surface 回來時**尺寸/DPI 改變**（少見），Presentation 無法沿用，會重建 WebView 並從記錄的位置續播（聲音會短暫中斷）。
- Android 12+ 對背景啟動前景服務有限制，部分情況可能無法啟動前景服務（會記 log，不會當機）。
- 觸控是以合成 MotionEvent 注入，YouTube 部分控制項（長按、雙擊快轉等）可能不如實機觸控。
- 部分車機 host 版本可能不支援 `onClick`（需 Car API level 5+）。
